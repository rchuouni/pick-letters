# PDF抜き出し 事前設定画面 使い方ガイド

このページは、PDFの特定の場所から文字を拾い、Excelに貼り付ける順番で並べるための設定画面です。
PDFや抽出した文字は保存されません。保存されるのは「設定」だけで、それもお使いのブラウザの中にだけ残ります。

---

## 1. 開く

1. `index.html` をブラウザ（Chrome か Edge を推奨）で開きます。
2. 初めて開くと、架空のサンプル請求書と、設定例が表示されます。

---

## 2. 見本のPDFを読み込む

1. 画面左上の「**見本PDFを選ぶ**」を押して、PDFを選びます。
   または、PDFを左側のページ部分へ**ドラッグ＆ドロップ**します。
2. 読み込むのは **1ページ目だけ** です。
3. 元に戻したいときは「**架空サンプル**」を押します。

---

## 3. ページを拡大・縮小する

- 「**＋**」「**−**」ボタンで拡大・縮小します。
- `Ctrl` キーを押しながらマウスホイールを回しても拡大・縮小できます。
- 「**幅に合わせる**」で横幅いっぱいに、「**全体を表示**」で1ページ全部が見える大きさになります。

---

## 4. 設定を新しく作る

1. 「**新規作成**」を押します。
2. 「**PDFの種類名**」に名前を入れます（例：`青葉精機 請求書`）。
3. 「**列の設定順**」を選びます。
   - 「右端の列から」：右側の列から順番に設定していきます。
   - 「左端の列から」：左側の列から順番に設定していきます。
4. 「**＋ 抜き出す列を追加**」で列を追加します。

---

## 5. 列ごとに範囲を指定する

1. 列カードを**ダブルクリック**します。
   または、Excel表の列見出し（A列、B列…）や値のセルを**ダブルクリック**します。
2. 範囲指定モードに入ります。ページの上に案内が出ます。
3. ページ上で、拾いたい場所を**ドラッグして囲みます**。
4. 囲んだあとの操作は次のとおりです。
   - 枠の中をドラッグ：枠を動かす
   - 角や辺の小さい四角をドラッグ：大きさを変える
   - 矢印キー（← ↑ → ↓）：少しずつ動かす
   - `Shift` ＋ 矢印キー：少しずつ大きさを変える
   - `Esc` キー、または「**指定を終える**」ボタン：範囲指定を終える

---

## 6. 拾う文字の規則を決める

「**拾う文字の規則**」で、次のどれかを選びます。

| 選択肢 | 使いどころ |
|---|---|
| 日付 | 2026/10/15、2026年10月15日 など |
| 金額 | ¥1,234,750 や 1,234円 など |
| 数字 | 数字だけ |
| 郵便番号 | 123-4567 の形 |
| 電話番号 | 03-1234-5678 の形 |
| 範囲内の1行ずつ | 範囲の中の行を、そのまま取る |
| 範囲内の文字すべて | 範囲の中の文字を全部まとめて取る |
| **その他** | 文字の形を自分で作る（次の7で説明） |
| 正規表現（上級者向け） | 普段は使わなくて大丈夫です |

---

## 7. 「その他」で文字の形を作る

「その他」を選ぶと、入力欄と下のボタンが出ます。

- **α（アルファ）**：英字1文字（A〜Z、a〜z）
- **β（ベータ）**：数字1文字（0〜9）
- **γ（ガンマ）**：記号1文字（- / . ¥ # など）
- **…（三点リーダー）**：直前の文字の種類が**1文字以上いくつでも**続く
- **空白**：空白があってもなくても可
- **1字消す**：カーソルの前の1文字を消す

ボタンを押すと、入力欄のカーソル位置に入ります。直接キーボードで打つこともできます。
α・β・γ・…以外の文字（`-` や `年` など）は、その文字そのものとして探します。

### 例

| 入力 | 拾えるもの | 例 |
|---|---|---|
| `ααα-ββββ-ββββ` | 英字3文字-数字4文字-数字4文字 | INV-2026-0142 |
| `αα-ββββ` | 英字2文字-数字4文字 | AB-1203 |
| `β…年β…月β…日` | 数字-年-数字-月-数字-日 | 2026年10月15日 |

入力欄の下に「**例**」が出るので、意図どおりか確認できます。

---

## 8. 目印の言葉で絞る（任意）

「**目印の言葉で絞り込む**」を開きます。

1. 「目印の言葉」に、近くにある文字を入れます（例：`お支払期限`）。
2. 「目印から見て」で「右側」か「左側」を選びます。

目印を含む行だけを対象にして、その右側（または左側）の文字から拾います。

---

## 9. 複数見つかったときの選び方

範囲の中で規則に当てはまる文字が複数見つかったら、「**いくつか見つかったら**」で選びます。

- 最初の1つ
- 最後の1つ
- ○番目（番号を入れる）
- すべて（スペース区切りでまとめる）

カードの「候補」に見つかった文字が並びます。候補の文字を押すと、それを使うように切り替わります。

---

## 10. 空欄の列を作る

- 「**＋ 空欄の列を追加**」で、何も入らない列を作れます。
- 既存の列では「**空欄の列に変える**」を押します。

Excelで列の位置を揃えるための枠として使います。

---

## 11. 列の順番を変える・削除する

- 列カードの「**↑**」「**↓**」で順番を変えます。
- 「**×**」で列を削除します。
- 列の「見出し」欄に、Excelの見出しになる名前を入れます。

---

## 12. 結果を確認する

- 各列カードの下に、取得できた値と「取得できた」「一致なし」などの表示が出ます。
- 一番下の表が、Excelに貼り付けたときの1行分の形です。
- 取れなかった列は、赤く表示されます。

---

## 13. Excelにコピーする

1. 必要なら「**見出し行も一緒にコピー**」にチェックを入れます。
2. 「**文字のまま貼る**」は、通常はオンのままにします。
   先頭の0や、日付の自動変換を防ぎます。
3. 「**コピー（Excelに貼り付け用）**」を押します。
4. Excelを開いて、貼り付けたいセルを選び、`Ctrl + V` で貼り付けます。
   列ごとに別のセルに入ります。

※ 自動でコピーできなかった場合は、下に出る枠が選択されています。`Ctrl + C` でコピーしてください。

---

## 14. 保存する

1. 「**保存**」を押します。
2. 同じ名前がすでにあるときは、もう一度「保存」を押すと上書きします。
3. 「**複製**」で、今の設定をもとに別の名前で作れます。
4. 「**削除**」は、2回押すと削除されます（誤操作防止）。

---

## 15. 別のPCへ移す（書き出し・読み込み）

設定はブラウザごとに保存されるため、別のPCでは見えません。移したいときは次のようにします。

1. 画面下の「**設定を別のPCへ移す**」を開きます。
2. 「**保存済みの設定をすべて表示**」を押します。
3. 「**表示した内容をコピー**」を押して、メモ帳などに保存します。
4. 別のPCでは、同じ画面を開き、「**貼り付けた内容を読み込む**」の枠に貼り付けて、「**貼り付けた内容を読み込む**」を押します。
   または「**JSONファイルから読み込む**」でファイルを選びます。

---

## よくある質問

**Q. PDFや抽出した文字は保存されますか？**
A. 保存されません。保存されるのは設定（範囲・規則・列の順番など）だけです。

**Q. 文字が取れません。**
A. 次を確認してください。
- 範囲が、文字の場所を囲んでいるか
- 「拾う文字の規則」が合っているか（「その他」の場合は、α・β・γ の並びが実際の文字と合っているか）
- 画像として取り込まれたPDFではないか（文字が選択できないPDFは取れません）

**Q. 別の場所にある同じ項目を取りたい。**
A. 列を複製し、範囲だけ引き直してください。

**Q. ネットにつながらないと使えませんか？**
A. 今の版は、PDF読み取りの部品をネットから読み込むため、初回はネット接続が必要です。
