# EXTRACT LETTERS HURRY 使い方ガイド

PDFの決まった場所から文字を拾い、決めた順番と区切り記号でつないで、Excelに貼り付けるための設定画面です。
PDFや拾った文字は保存されません。保存されるのは「設定」だけで、それもお使いのブラウザの中にだけ残ります。

---

## 画面の並び

上から順に、次の4つが並んでいます。

1. **保存済みの設定**：PDFの種類を選ぶ・名前を付けて保存する
2. **Excelに貼り付けたときの形**：アウトプットの見た目と、コピーボタン
3. **見本PDF**（左）と **アウトプットの項目**（右）：範囲と規則の設定
4. **設定を別のPCへ移す**：書き出し・読み込み

画面右上の「**よくある質問**」から、詳しいFAQを言葉で探せます。

---

## 1. 開く

1. `index.html` をブラウザ（Chrome か Edge を推奨）で開きます。
2. 初めて開くと、架空のサンプル請求書と、設定例が表示されます。
3. 保存した設定は、**同じブラウザで同じ場所のファイル**を開くと、最後に使ったものが自動で開きます。

---

## 2. 見本のPDFを読み込む

1. 「**見本PDFを選ぶ**」を押して、PDFを選びます。
   または、PDFをページ部分へ**ドラッグ＆ドロップ**します。
2. 読み込むのは **1ページ目だけ** です。
3. 元に戻したいときは「**架空サンプル**」を押します。

---

## 3. ページを拡大・縮小する・回す

- 「**＋**」「**−**」ボタンで拡大・縮小します。
- `Ctrl` キーを押しながらマウスホイールを回しても拡大・縮小できます。
- 「**幅に合わせる**」で横幅いっぱいに、「**全体を表示**」で1ページ全部が見える大きさになります。
- PDFが横向きや逆さまのときは、「**↻ 右に90°回す**」を押します。押すたびに時計回りに90°ずつ回ります。
  - 指定済みの範囲も、ページと一緒に回ります。
  - 向きはPDFの種類ごとの設定として保存され、同じ種類のPDFは毎回その向きで読み取ります。

---

## 4. 設定を新しく作る

1. 「**新規作成**」を押します。
2. 「**PDFの種類名**」に名前を入れます（例：`青葉精機 請求書`）。
3. 「**＋ 抜き出す項目を追加**」で項目を追加します。
   項目カードは **上から順に 1番目、2番目…** で、1番目がアウトプットの先頭になります。

---

## 5. 項目の順番を入れ替える

1. 項目カードの左上の **⠿** をつかんで、上下に**ドラッグ**します。
2. ドラッグ中はカードが小さくたたまれ、番号はすぐに付け直されます。
3. 離したところで順番が決まります。

キーボードでは、⠿ を選んで `↑` `↓` キーで動かせます。
「**×**」で項目を削除します。

---

## 6. 項目ごとに範囲を指定する

1. 項目カードの余白を**ダブルクリック**します。
   または、「Excelに貼り付けたときの形」で、その項目を**ダブルクリック**します。
2. 範囲指定モードに入ります。ページの上に案内が出ます。
3. ページ上で、拾いたい場所を**ドラッグして囲みます**。
4. 囲んだあとの操作は次のとおりです。
   - 枠の中をドラッグ：枠を動かす
   - 角や辺の小さい四角をドラッグ：大きさを変える
   - 矢印キー（← ↑ → ↓）：少しずつ動かす
   - `Shift` ＋ 矢印キー：少しずつ大きさを変える
   - `Esc` キー、または「**指定を終える**」ボタン：範囲指定を終える

---

## 7. 拾う文字の規則を決める

「**拾う文字の規則**」で、次のどれかを選びます。

| 選択肢 | 使いどころ |
|---|---|
| その他 | 文字の形を自分で作る（次の8で説明） |
| 日付 | 2026/10/15、2026年10月15日、令和8年10月15日、20261015 など |
| 金額 | ¥1,234,750 や 1,234円 など |
| 数字 | 数字だけ |
| 郵便番号 | 123-4567 の形 |
| 電話番号 | 03-1234-5678 の形 |
| 範囲内の1行ずつ | 範囲の中の行を、そのまま取る |
| 範囲内の文字すべて | 範囲の中の文字を全部まとめて取る |
| 正規表現（上級者向け） | 普段は使わなくて大丈夫です |

---

## 8. 「その他」で文字の形を作る

「その他」を選ぶと、入力欄と下のボタンが出ます。

- **α（アルファ）**：英字1文字（A〜Z、a〜z）
- **β（ベータ）**：数字1文字（0〜9）
- **γ（ガンマ）**：記号1文字（- / . ¥ # など）
- **…（三点リーダー）**：直前の文字の種類が**1文字以上いくつでも**続く
- **空白**：空白があってもなくても可
- **1字消す**：カーソルの前の1文字を消す

α・β・γ・…以外の文字（`-` や `年` など）は、その文字そのものとして探します。

| 入力 | 拾えるもの | 例 |
|---|---|---|
| `ααα-ββββ-ββββ` | 英字3文字-数字4文字-数字4文字 | INV-2026-0142 |
| `αα-ββββ` | 英字2文字-数字4文字 | AB-1203 |
| `αβ…` | 英字1文字＋数字が何桁でも | T1234567890123 |

---

## 8-2. 文字数を決めて取り出す（「範囲内の文字すべて」「範囲内の1行ずつ」）

「拾う文字の規則」で「**範囲内の文字すべて**」か「**範囲内の1行ずつ**」を選ぶと、「**取り出す文字数**」が出ます。

1. 「左から」か「右から」を選びます。
2. 「**−**」「**＋**」ボタン、または数字の入力で文字数を決めます（0 は全部）。
3. 取り出す部分が色付きで表示されるので、確認します。

例：「みずほ銀行大阪支店」で「左から 5 文字」にすると、「**みずほ銀行**」がアウトプットになります。

- 「**空白を取り除いてから数える**」にチェックを入れると、空白を詰めてから数えます。
- 「**全部にする**」で 0（全部）に戻ります。

---

## 9. 日付の書き方を直す

「拾う文字の規則」で「**日付**」を選ぶと、「**日付の書き方**」が出ます。拾った日付を、選んだ形に直してアウトプットします。

| 選択肢 | 2026年10月15日 を拾ったとき | 2026/1/1 を拾ったとき |
|---|---|---|
| そのまま | 2026年10月15日 | 2026/1/1 |
| 2026/01/05 | 2026/10/15 | 2026/01/01 |
| 2026/1/5 | 2026/10/15 | 2026/1/1 |
| 2026-01-05 | 2026-10-15 | 2026-01-01 |
| 2026.01.05 | 2026.10.15 | 2026.01.01 |
| 20260105 | 20261015 | 20260101 |
| 2026年1月5日 | 2026年10月15日 | 2026年1月1日 |
| 2026年01月05日 | 2026年10月15日 | 2026年01月01日 |
| 令和8年1月5日（和暦） | 令和8年10月15日 | 令和8年1月1日 |

PDFの日付が和暦（令和・平成・昭和）や `20261015` の形でも拾えます。
2026/2/30 のようなありえない日付は、直さずにそのまま出します。

---

## 10. 数字・金額の書き方を直す

「拾う文字の規則」で「**数字**」か「**金額**」を選ぶと、「**数字の書き方**」が出ます。

| 選択肢 | 1234567 | 1,234,567 |
|---|---|---|
| そのまま | 1234567 | 1,234,567 |
| カンマを付ける | 1,234,567 | 1,234,567 |
| カンマを外す | 1234567 | 1234567 |

- 「**小数点以下を消す**」にチェックを入れると、小数点より後ろを切り捨てます（12.5 → 12、四捨五入はしません）。
- 「金額」で「カンマを付ける」「カンマを外す」を選ぶと、¥ や 円 を外して数字だけにします。
- 「カンマを付ける」では、0012 のような先頭の0は外れます。

### 単位を付ける

「数字の書き方」の下の「**単位を付ける**」で選びます。

| 選択 | 例（1,234 を拾ったとき） |
|---|---|
| 付けない | 1,234 |
| 円 | 1,234円 |
| US$ | 1,234US$ |
| RMB | 1,234RMB |
| その他 | 入力した単位を付ける（例：「個」→ 1,234個） |

「付ける位置」で「前」を選ぶと、US$1,234 のように数字の前に付きます。

---

## 11. 目印の言葉で絞る（任意）

「**目印の言葉で絞り込む**」を開きます。

1. 「目印の言葉」に、近くにある文字を入れます（例：`お支払期限`）。
2. 「目印から見て」で「右側」か「左側」を選びます。

---

## 12. 複数見つかったときの選び方

「**いくつか見つかったら**」で選びます。

- 最初の1つ／最後の1つ／○番目（番号を入れる）／すべて（スペース区切りでまとめる）

カードの「候補」に見つかった文字が並びます。候補を押すと、それを使うように切り替わります。

---

## 13. 入力した文字の項目を作る

PDFから拾わず、決まった文字をアウトプットに入れたいときに使います。

1. 「**＋ 入力した文字の項目を追加**」を押します。
   既存の項目では「**入力した文字の項目に変える**」を押します。
2. 「**アウトプットに入れる文字**」に入力します（例：`仕入`）。
3. その文字が、そのままアウトプットに入ります（例：`INV-2026-0142/仕入/2026/10/15`）。

文字を空欄のままにすると、区切り記号が「/」なら `A//C` のように位置だけが残ります。

---

## 14. アウトプットの形を決める

「**Excelに貼り付けたときの形**」で設定します。

1. 「**貼り付け方**」を選びます。
   - **1つのセルにまとめる（A1だけ）**：標準。すべての項目を区切り記号でつないで、1つのセルに入れます。
   - **列ごとに分ける（A1・B1・C1…）**：項目ごとに別のセルに入れます。
2. 「**区切り記号**」に、項目と項目の間に入れる記号を入力します。
   - 「/」と入れると：`アウトプットA/アウトプットB/アウトプットC`
   - 空欄にすると：`アウトプットAアウトプットBアウトプットC`
   - 「/」「・」「-」「、」などは、横のボタンでも選べます。
3. 必要なら「**空の項目は、区切り記号ごと省く**」にチェックを入れます（オフ：`A//C`、オン：`A/C`）。

A1セルに入る文字がそのまま表示され、項目ごとに色の下線が付きます。取れなかった項目は赤く表示されます。

---

## 15. Excelにコピーする

1. 必要なら「**見出し行も一緒にコピー**」にチェックを入れます（見出しはA1、値はA2）。
2. 「**文字のまま貼る**」は、通常はオンのままにします。
3. 「**コピー（Excelに貼り付け用）**」を押します。
4. Excelで A1セルを選び、`Ctrl + V` で貼り付けます。

あとで列ごとに分けたいときは、Excelの「データ」→「区切り位置」で、同じ区切り記号を指定してください。

---

## 16. 保存する

1. 「**保存**」を押します。
2. 同じ名前がすでにあるときは、もう一度「保存」を押すと上書きします。
3. 「**複製**」で、今の設定をもとに別の名前で作れます。
4. 「**削除**」は、2回押すと削除されます。

以前の版で「右端から」の順番で作った設定は、開いたときに1番目が一番上に来るよう自動で並べ直します。アウトプットの中身は変わりません。

---

## 17. 別のPCへ移す（書き出し・読み込み）

1. 画面下の「**設定を別のPCへ移す**」を開きます。
2. 「**保存済みの設定をすべて表示**」→「**表示した内容をコピー**」を押して、メモ帳などに保存します。
3. 別のPCでは、同じ枠に貼り付けて「**貼り付けた内容を読み込む**」を押します。
   または「**JSONファイルから読み込む**」でファイルを選びます。

---

## よくある質問（抜粋）

画面右上の「**よくある質問**」ボタンから、もっと詳しいFAQを言葉で検索できます。

**Q. PDFや拾った文字は保存されますか？**
A. 保存されません。保存されるのは設定（範囲・規則・順番・書き方・区切り記号など）だけです。

**Q. ウィンドウを閉じたら、また設定し直しですか？**
A. いいえ。保存した設定は残ります。同じブラウザで、同じ場所のHTMLファイルを開いてください。

**Q. 文字が取れません。**
A. 範囲が文字の場所を囲んでいるか、規則が実際の文字の形と合っているか、画像だけのPDFでないかを確認してください。

**Q. ネットにつながらないと使えませんか？**
A. 今の版は、PDF読み取りの部品をネットから読み込むため、ネット接続が必要です。
